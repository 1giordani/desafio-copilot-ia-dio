# 🤖 Desafio DIO - Microsoft Copilot e Azure OpenAI

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da Digital Innovation One (DIO).

O objetivo é explorar conceitos relacionados à Inteligência Artificial, Microsoft Copilot, Azure OpenAI, filtros de conteúdo e criação assistida por IA.

Durante o desenvolvimento, foram realizados estudos e experimentos com diferentes funcionalidades e prompts.

---

## 🎯 Objetivos de aprendizagem

- Compreender conceitos de Inteligência Artificial generativa;
- Explorar funcionalidades do Microsoft Copilot;
- Conhecer o Azure OpenAI;
- Entender a importância dos filtros de conteúdo;
- Criar e testar prompts;
- Documentar experiências técnicas;
- Utilizar o GitHub para compartilhar conhecimento e projetos.

---

## 🤖 Microsoft Copilot

O Microsoft Copilot utiliza Inteligência Artificial para auxiliar usuários em diversas tarefas.

Entre os recursos estudados estão:

- Geração de textos;
- Resumos;
- Pesquisa de informações;
- Criação de conteúdo;
- Auxílio na programação;
- Interação por meio de conversação.

---

## 🧠 Azure OpenAI

O Azure OpenAI permite utilizar modelos de Inteligência Artificial da OpenAI dentro do ambiente Microsoft Azure.

Durante o estudo foram abordados conceitos como:

- Inteligência Artificial generativa;
- Modelos de linguagem;
- Engenharia de prompts;
- Geração de conteúdo;
- Segurança;
- Filtros de conteúdo.

---

## 🛡️ Filtros de conteúdo

Os filtros de conteúdo são mecanismos importantes para tornar o uso da Inteligência Artificial mais seguro e responsável.

Eles ajudam a identificar e controlar determinados tipos de conteúdo que podem ser considerados inadequados ou que apresentam riscos.

---

## ✍️ Exemplos de prompts

### Prompt 1 - Inteligência Artificial

> Explique o que é Inteligência Artificial generativa utilizando uma linguagem simples para uma pessoa que está começando a estudar tecnologia.

### Prompt 2 - Programação

> Explique como funciona uma estrutura condicional IF em JavaScript e apresente um exemplo simples.

### Prompt 3 - Estudos

> Crie um plano de estudos para aprender os fundamentos de JavaScript começando pelos conceitos básicos.

### Prompt 4 - GitHub

> Explique como criar um README.md organizado para apresentar um projeto de programação no GitHub.

## 📖 Principais aprendizados

Durante este desafio pude compreender melhor:

1. O conceito de Inteligência Artificial generativa;
2. A importância de elaborar bons prompts;
3. O funcionamento de ferramentas como o Microsoft Copilot;
4. Conceitos básicos relacionados ao Azure OpenAI;
5. A importância dos filtros de conteúdo;
6. A utilização da IA como ferramenta de apoio ao desenvolvimento;
7. A importância da documentação técnica;
8. A utilização do GitHub para criação de portfólio.

---

## 💡 Reflexão

Este desafio mostrou como a Inteligência Artificial pode ser utilizada como ferramenta de apoio aos estudos e ao desenvolvimento de software.

Também foi possível perceber que a qualidade da resposta obtida depende da clareza e do contexto fornecido no prompt.

A IA pode aumentar a produtividade, mas é importante que o desenvolvedor compreenda o código, valide as informações e utilize a tecnologia de maneira responsável.
