# ✍️ Exemplos de Prompts

Este arquivo apresenta exemplos de prompts utilizados durante os estudos sobre Inteligência Artificial e ferramentas Microsoft Copilot.

---

## 1. Inteligência Artificial Generativa

### Objetivo

Compreender o conceito de Inteligência Artificial generativa.

### Prompt

> Explique o que é Inteligência Artificial generativa utilizando uma linguagem simples para uma pessoa que está começando a estudar tecnologia.

### Aprendizado

A IA generativa é capaz de produzir novos conteúdos a partir dos padrões aprendidos durante seu treinamento, podendo gerar textos, imagens, códigos e outros tipos de conteúdo.

---

## 2. Microsoft Copilot

### Objetivo

Conhecer as possibilidades de utilização do Microsoft Copilot.

### Prompt

> Explique cinco maneiras pelas quais o Microsoft Copilot pode ajudar um estudante de tecnologia no dia a dia.

### Aprendizado

O Copilot pode auxiliar em pesquisas, explicações de conceitos, geração de ideias, criação de textos e apoio ao desenvolvimento de software.

---

## 3. JavaScript

### Objetivo

Utilizar IA como apoio ao aprendizado de programação.

### Prompt

> Explique como funciona uma estrutura condicional IF em JavaScript e apresente um exemplo simples.

### Aprendizado

A estrutura IF permite executar determinado trecho de código quando uma condição é verdadeira.

---

## 4. GitHub

### Objetivo

Aprender a documentar um projeto.

### Prompt

> Explique como criar um README.md organizado e profissional para um projeto no GitHub.

### Aprendizado

O README é importante para apresentar o objetivo do projeto, tecnologias utilizadas, funcionamento, aprendizados e informações relevantes para outras pessoas.

---

## 5. Engenharia de Prompts

### Objetivo

Compreender a importância de fornecer contexto para a IA.

### Prompt

> Explique por que fornecer contexto, objetivo e informações específicas melhora a qualidade das respostas de uma ferramenta de Inteligência Artificial.

### Aprendizado

Quanto mais claro e específico for o prompt, maiores são as chances de obter uma resposta adequada ao objetivo desejado.

---

## 📌 Conclusão

Os testes realizados demonstraram que a Inteligência Artificial pode ser utilizada como uma ferramenta de apoio aos estudos e ao desenvolvimento de software.

Entretanto, é importante analisar e validar as respostas geradas antes de utilizá-las.
